# Deletion candidates after MACRO-ORDEN

No path in this list is deleted by the current migration. Each item requires a
separate review and explicit approval after the compatibility window.

## Candidate group A — temporary compatibility

- `src/res023_lab/*.py` facade wrappers.
- Root-level `src/ipa/*.py` compatibility wrappers such as `ipa/reporter_*.py`,
  `ipa/lancedb_index.py` and `ipa/tutor_contracts.py`.
- Root `scripts/*.py` entrypoints once all callers use the organized wrappers in
  `scripts/cli`, `scripts/benchmarks`, `scripts/validation` and `scripts/operations`.

Precondition: public imports, dashboard jobs, docs and tests use the organized
paths; deprecation window has ended.

## Candidate group B — archived development material

- `local_archive/scripts/_*.py` scratch utilities.
- `local_archive/scripts/__check_history.py`.
- `local_archive/scripts/proc_wrappers/proc_*.py` — six process wrappers
  replaced by `ipa.dashboard.process_specs` / `process_runner` /
  `process_state` + `scripts/operations/run_job.py`. See
  `local_archive/scripts/proc_wrappers/MANIFEST.md` for validation evidence.
- `local_archive/experiments/*` superseded experiment documents.
- `local_archive/benchmarks/reporter_v1.json` after fixture migration is accepted.
- `local_archive/legacy_res023_lab/*` original implementations retained during
  package migration.

Precondition: public EKS/docs/manifests contain conclusions and no reproducible
runner depends on the archived path.

## Candidate group C — generated local build artifacts

- `build/`;
- `dist/`;
- `src/ipa.egg-info/`;
- generated bytecode and caches.

These are reconstructible and ignored. They can be cleaned in a dedicated
confirmed cleanup operation; they are not part of the public surface.

## Protected paths

The following are not deletion candidates in this migration:

- `Landing/` with unprocessed artifacts;
- `Archive/`;
- `models/`;
- `exllamav3-dev/`;
- source fixtures under `data/sample/input/`;
- authoritative contracts;
- active outputs required for local recovery.
