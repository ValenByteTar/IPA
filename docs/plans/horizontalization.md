# Horizontalization research plan

Horizontal retrieval, persistent identity, episodic memory, navigation and tool
use are research directions, not current production guarantees.

Each proposal must be tested independently:

1. vertical retrieval vs hierarchical navigation;
2. no memory vs episodic memory;
3. no planner vs deterministic bounded planner;
4. single-pass curation vs tiered curation;
5. topic association vs universal topic identity.

No graph database, open-ended ReAct loop or universal `topic_cluster_id` should be
introduced without an experiment that proves incremental value and defines
ownership, budgets and rollback.
